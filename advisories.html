Access to Vulnerability Lookup gives you alerts on new vulnerabilities. It lets you search the CVE filtered by vendor, product, CVSS or CWE.

ICS-CSIRT used to provide access to OpenCVE, but unfortunately the OpenCVE instance is no longer available. Supporting its setup required significant effort and resources. Additionally, the data provided by Vulnerability Lookup is more comprehensive than what OpenCVE provided. Therefore, the support for the OpenCVE instance via ICS-CSIRT was discontinued. Note that Vulnerability Lookup is not associated with ICS-CSIRT.

Access Vulnerability Lookup (at CIRCL)

  • Vulnerability information
  • Notifications per vendor
  • Security updates
  • CVE data
